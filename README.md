# 听一句

“听一句”是一个本机逐句循环朗读工具：输入正文后，Kokoro 会反复朗读当前句；只有点击“下一句”，才会切换到下一句。

## 启动

在 macOS 上双击 `启动听一句.command`。启动器会自动完成三件事：

1. 首次运行时，在 `~/Library/Caches/tingyiju/venv` 创建独立语音环境并安装依赖。
2. 准备 `Kokoro-82M-v1.1-zh`；首次朗读时从本机缓存载入，模型缺失时自动下载。
3. 启动只监听 `127.0.0.1:8765` 的服务并打开浏览器。

首次安装和首次载入模型会较慢；之后启动会直接复用环境和模型缓存。关闭启动器所在的终端窗口即可停止服务。不要直接双击 `index.html`，那样无法连接语音服务。

## 使用

1. 粘贴要抄写的正文；句号、问号、感叹号和换行会先形成自然句。
2. 设置每段的期望最短字数和最长上限；默认范围为 10–18 字。
3. 从四个固定 Kokoro 音色中选择一个：`zf_001`、`zf_004`、`zm_010`、`zm_025`。
4. 设置语速和重复间隔，点击“开始朗读”。
5. 写完当前句后点击“下一句”；最后一句会显示“完成”。

正文只在浏览器当前页面和本机服务之间传递，不会发送到外部语音平台。生成结果按“模型版本 + 音色 + 语速 + 文本”缓存在 `~/.cache/tingyiju/audio`；重复播放同一句会直接重放当前音频。

## 自适应分段

应用先按句末标点和换行保留自然句；自然句超过最长上限后，再使用全局均衡算法寻找切分位置：

1. 优先选择逗号、分号、冒号和顿号等自然停顿。
2. 没有合适标点时，优先选择中文词语或英文单词边界。
3. 在不超过最长上限的前提下，尽量缩小各段长度差距。
4. 保留自然句内部的全部字符和空格；同一自然句的片段重新拼接后仍与切分前一致。

“最长上限”是硬约束；“期望最短”用于指导均衡。当文本总长度无法同时满足两项要求时，会优先保证不超长和各段长度接近。例如 19 个字设置为 10–10 时，会拆成 9 字和 10 字，而不是产生超长片段。

## 操作规则

- 朗读自然结束后，只等待设定间隔，再重复当前句，不会自动推进。
- “上一句”“下一句”会立即取消旧的下载、音频和等待任务。
- “暂停”会保留当前句；“继续”从当前句句首重新朗读。
- 修改文章会立即清除旧分句，需要重新开始。
- 页面切到后台会自动暂停，回到页面后需手动点击继续。
- 右方向键下一句，左方向键上一句，空格暂停或继续，Esc 结束；编辑输入框时不会触发快捷键。

## 本地验证

前端测试需要 Node.js 18 或更高版本：

```text
node --test test/*.test.js
```

服务端基础测试不依赖 Kokoro 运行环境：

```text
python3 -m unittest test/test_server.py
```

语音模型、依赖和生成缓存都位于本机，不产生云端调用费用。
